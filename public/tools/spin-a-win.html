📋 How to Use

1. Edit any prize slot below - enter drink specials, food deals, or prizes (e.g., "$5 Jack Shots", "Free Appetizer", "Next Song Choice")

2. Check the box ☑️ next to prizes that should include your extra message (e.g., "For The Next 15 Minutes")

3. Click SPIN in the center of the wheel or use the big Spin button

4. Use Pop Out to display the wheel on a TV or projector - it remembers its position!

🎁 Prize Slots (Check box to add extra message & confetti for a win!)
💬 Extra Message for Checked Prizes:
When a checked prize wins, this message will be added. Example: "$5 Jack Shots" + "For The Next 15 Minutes" = "$5 Jack Shots For The Next 15 Minutes"
🏠 Venue Welcome Message (shows before spin):
This message displays on the pop-out screen before any prize is won. Great for welcome messages or promotions!
